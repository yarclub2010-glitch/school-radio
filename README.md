# Школьное радио

Школьники загружают музыку → модератор (учитель) одобряет → треки попадают в общий плейлист и играют в актовом зале на переменах.

Стек: Django 6.1 + SQLite, фронтенд на чистом HTML/CSS/JS (без сборщиков).

## Страницы

| Адрес | Что там |
|---|---|
| `/` | Плейлист одобренных треков, поиск, прослушивание на своём устройстве, «Сейчас в актовом зале» |
| `/upload/` | Загрузка трека (MP3/OGG/M4A/WAV, до 20 МБ) — уходит на проверку |
| `/hall/` | Экран для компьютера в актовом зале: перемешивает треки, играет только во время перемен, плавно затихает к звонку |
| `/moderation/` | Для учителей: прослушать и одобрить/отклонить новые треки |
| `/admin/` | Расписание перемен, все треки, пользователи |

## Запуск

```bash
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python manage.py migrate
.venv\Scripts\python manage.py createsuperuser
.venv\Scripts\python manage.py runserver 0.0.0.0:8010
```

Открыть http://127.0.0.1:8010/. С других устройств в школьной сети — `http://<IP этого компьютера>:8010/`.

## Расписание перемен

`/admin/` → «Расписание перемен» → добавить, например, «После 1 урока» 09:25–09:35, дни `0,1,2,3,4` (Пн–Пт).
Если расписание не задано, зал играет без остановки.

На компьютере в зале откройте `/hall/` и один раз нажмите «Запустить эфир» — браузеры не включают звук без клика.
